Core principle

“Redact only what is asked.
Over-redaction is content loss.”

◎

Word-level precision

OCR boxes matched by exact text — never whole lines. Neighbouring words stay razor sharp.

◉

Track, don't drift

CSRT + anchor appearance check. Teleports rejected, look-alikes ignored, lost tracks stop cold.

⬣

Faces are sacred

Detector-assisted target: "face" masks only the overlapping detection. Every other face provably untouched.

The blind-operator loop — how a no-vision model edits video

Blind model. Sighted tools. Zero frames sent anywhere.

Your LLM has no eyes — it can never open the .mp4. So redact-tool becomes its eyes and hands: inspect translates pixels into words it can read (JSON text), the model reasons over that text, and render + verify execute + prove the edit. This is the whole trick — make video editable as pure text.

agent log — text-only model, no vision⊘ vision off
1

👁→📝 inspect pixels → text

Samples frames, returns JSON: texts[] with words + runs, faces[] with tracklets + boxes. The model finally “sees” — as text.

2

🙋 ground with the user never guess

Two faces? “Top-left (0–4s) or right column (9–15s)?” The model stops and asks — a wrong guess leaks PII or vandalises content.

3

📦 anchor without seeing JSON only

Face anchor = tracklet start_box @ first_frame. Object anchor = user / pick_region.py pixels. Timestamps via inventoried fps. Nothing invented.

4

⚙️ render + ✓ verify prove it

Validate → mask → rescan output for leftovers + retrace tracks. exit 0 = ship. text_leftovers = tighten spec, never ship.

🔒 frames + OCR text stay on your disk · PaddleOCR local · YuNet/Haar on CPU · nothing sent to any remote service

Pipeline — built for blind agents

Inspect → Specify → Render → Verify. No eyes required.

1

👁 inspect eyes for planning

Samples every Nth frame → JSON inventory: video dims, distinct words with runs, face tracklets with start/end boxes.

python redact-tool.py inspect --video in.mp4 --out inv.json
2

🎯 pick_region anchor with pixels

Opens the frame at --time 00:00:02.5. Drag a rectangle, press S — exact x, y, w, h for your track_box.

python pick_region.py --input Test.mp4 --time 00:00:02.5
3

⚙ render deterministic

Validates the spec field-by-field, fails fast on bad boxes. Emits out.mp4 + out.report.json. Never overwrites input.

python redact-tool.py render --video in.mp4 --out out.mp4 --spec actions.json
4

✓ verify prove it

Rescans output for readable leftovers, retraces each track. Exit 0 = ship. Exit 1 + text_leftovers = tighten spec.

python redact-tool.py verify --video out.mp4 --spec actions.json --source in.mp4
--fresh discard resume frames --keep-audio keep audio (off by default) --max-seconds N preview first N s --help lists everything

Built for no-vision models

        
The model plans in text.
Redact-tool edits the pixels.

        
Give any text-only model TOOL.md: the Job Spec schema, four PII primitives, worked examples. It never parses video — it emits frame numbers, boxes, PII strings and time windows; Redact-tool validates field-by-field and renders deterministically. Unknown keys and out-of-range values fail fast before a single frame is touched.

        
    
          
  • Execution-only — never infers PII beyond what the user asked. No guessing faces.
    • 
          
  • Blind-safe — every box grounded in inspect or user pixels; invented coordinates fail validation.
    • 
          
  • Leaking chat? — region_mask (fast/safe) or text_mask scoped to the chat region with regex PII match.
    • 
          
  • Report like a planner — frames masked, what verify proved, what’s left — numbers, not adjectives.

Limitations — read before shipping

        
Honest redaction.

        
    
          
  • Only as good as the spec — not a guarantee of anonymity.
    • 
          
  • OCR can miss text; text_mask matches whatever OCR reads — always review.
    • 
          
  • blur/pixelate obscure; only black is unrecoverable.
    • 
          
  • Lost stays lost — re-entry needs a new action + anchor.
    • 
          
  • Always review the exported video before sharing.
